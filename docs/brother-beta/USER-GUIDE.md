# Sakefolio：使い始めるときの案内

この案内は所有者が最終試験に合格した後に渡します。
現在は招待保留です。
アプリの正式URLは所有者から直接受け取ってください。

1. iPhoneのSafariでURLを開き、「Googleで始める」から自分のアカウントを選びます。要求されるのは、このアプリで使うGoogle Driveのファイルに限る権限です。
2. 「日本酒を記録する」から銘柄・酒蔵・飲んだ日・評価を入力。ラベル写真と感想も追加できます。
3. 保存完了が表示されてから一覧を確認します。記録や写真は自分のGoogle Drive/Sheetsへ保存されます。
4. 一覧の「編集」で修正。「ゴミ箱へ」は非表示にする操作で、ゴミ箱の「復元」で戻せます。元の行や写真を完全削除する操作ではありません。
5. 定期的に「写真付き日本酒バックアップ」をファイルへ保存してください。CSV/写真IDだけのJSONには画像本体が含まれません。バックアップには個人の記録が含まれるため、公開しないでください。

「保存完了が未確認」「通信エラー」と出たら、入力を変えず、同じアカウントで再接続して同じ保存ボタンを押してください。
結果が不明なまま別の新規記録を作ると重複の原因になります。
ページを閉じた後は、同じ入力と写真の再選択が必要になることがあります。
認証は期限切れになります。
Googleのテストモードでは同意も原則7日で失効するため、再接続が必要です。

他人の記録が見える、写真が違う、同じ記録が増える場合は保存を止め、所有者へ操作・時刻・エラー文を伝えてください。
パスワード、認証コード、トークンを送らないでください。
中国本土でのGoogle接続と保存は保証されていません。
オフライン状態では日本酒クラウド版に新規保存できません。
